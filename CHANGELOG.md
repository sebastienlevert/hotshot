## 0.1.0

- Native WinUI 3 tray utility for x64 and ARM64 Windows.
- Silent full-screen, monitor, window and region PNG captures with clipboard support.
- PowerToys-inspired settings, configurable global shortcuts and token-based naming.
- Lightweight annotation editor with capture history, cropping, undo/redo and editable originals.
- MP4 recording with optional audio and GIF conversion.
- GitHub Releases installers, managed portable bundles and automatic background updates.
- Release Please version/changelog pull requests and automated architecture-specific packaging.
